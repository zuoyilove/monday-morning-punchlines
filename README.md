## The joke

> I hired five alarms for Monday morning. Four walked out — the fifth unionised and now charges me rent.

The setup hires the alarms like staff; the punchline turns the morning
routine into a labour dispute, so the laugh lands on the last alarm's
demand, not on a complaint about Mondays.

## Run

```sh
node main.ts
```
